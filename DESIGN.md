# Design system

The dashboard is an executive operations surface: quiet navy navigation, warm off-white work area, precise data typography, and restrained coral only where attention is required. The first viewport shows the portfolio disposition and the highest-risk work immediately. Project detail keeps evidence and actions adjacent to the score. Synthetic data is marked in the UI.

Tokens live in `web/styles.css`. Status colors are semantic, while interactive controls use a single blue accent. Tables and evidence lists provide density without nesting cards. Responsive layouts preserve the portfolio list and project investigation on narrow screens.
